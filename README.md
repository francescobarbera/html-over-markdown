# HTML over Markdown

**Sometimes the best AI explanation isn't a document. It's a tiny interactive interface.**

HTML over Markdown is a collection of reusable prompts that ask coding agents to turn source code, logs, and complex ideas into **self-contained, disposable HTML pages**. No frameworks, dependencies, build steps, or deployments are needed to open an example.
